OpenBitFun 1.0.9 桌面端更新

- 多设备工作台：可在侧边栏、会话标签和 Agent companion 中浏览其他设备的工作区与会话，支持跨设备打开项目、创建项目、重命名设备和管理会话。
- 远程工作区与控制：SSH 支持 ProxyCommand 与预认证隧道，改进 SFTP 恢复、远程搜索和终端链接；CLI 可提供文件、Git、会话用量及远程控制能力，并支持向其他设备派发任务。
- 移动端控制：新增设备模型角色设置、命令面板、会话用量查看和子 Agent 实时任务卡片；支持一键发送下一轮建议，并改进会话与设备切换体验。
- Generative UI：集成 OpenUI Lang 流式交互界面，提供组件库、HTML 渲染、交互状态与能力调用，跟随 OpenBitFun 明暗主题和语义颜色，并改进渲染失败后的修复体验。
- Agent 与扩展：项目 Hooks 可在远程工作区运行，Python 程序化工具调用可用，Claw 与 Cowork 默认支持 Generative UI，并扩展 Pages 管理能力。
- 图片生成与 ACP：ChatGPT 订阅使用独立图片请求；外部 ACP 会话创建时显示启动进度，失败时提供错误提示与重试，减少初始化元数据的重复读取。
- 桌面与会话体验：新增 Windows 桌面卡片固定，改进模型设置、项目默认模型与模式、上下文浏览、全局搜索、历史加载和流式会话恢复。
- 输入与消息：改进输入框撤销、重做及中文输入分组，大段粘贴发送后可查看、复制和重新编辑完整内容，修复展开消息被外部点击意外收起的问题。
- 长会话性能：按 Markdown 语义分段和内容块限制渲染开销，优化代码高亮、流式前缀复用与历史滚动，保留搜索、摘录、书签及阅读位置。
- 远程传输性能：支持协商 Zstd 消息压缩，兼容旧版设备；复用会话预热、并行连接准备和历史读取，减少打开会话、发送消息及空闲状态查询的等待。
- 稳定性与统计：修复 Peer Device 会话投影与回滚、Relay 路由、SSH 连接恢复、远程文件操作和会话发现问题；修复会话结算时 token 用量丢失及输出速率统计偏低的问题，并优化工作区切换与窗口缩放。
