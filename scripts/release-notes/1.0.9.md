OpenBitFun 1.0.9 桌面端更新

- 多设备工作台：可在侧边栏、会话标签和 Agent companion 中浏览其他设备的工作区与会话，支持跨设备打开项目、创建项目、重命名设备和管理会话。
- 远程工作区与控制：SSH 支持 ProxyCommand 与预认证隧道，改进 SFTP 恢复、远程搜索和终端链接；CLI 可提供文件、Git、会话用量及远程控制能力，并支持向其他设备派发任务。
- 移动端控制：新增设备模型角色设置、命令面板、会话用量查看和子 Agent 实时任务卡片；支持一键发送下一轮建议，并改进会话与设备切换体验。
- Agent 与扩展：项目 Hooks 可在远程工作区运行，Python 程序化工具调用可用，Claw 与 Cowork 默认支持 Generative UI，并扩展 Pages 管理能力。
- 桌面与会话体验：新增 Windows 桌面卡片固定，改进模型设置、项目默认模型与模式、上下文浏览、全局搜索、历史加载和流式会话恢复。
- 稳定性与性能：修复 Peer Device 会话投影与回滚、Relay 路由、SSH 连接恢复、远程文件操作和会话发现问题；优化跨设备会话打开、历史读取、工作区切换及窗口缩放。
