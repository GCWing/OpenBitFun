OpenBitFun 1.0.8 桌面端更新

- 模型与 AI：新增按轮次的智能模型路由、上下文压缩与摘要队列，支持自适应思考、独立连接探测、模型池与订阅配额展示，完善模型切换和图像输入限制。
- Agent 与工具：新增程序化工具调用和内置图像生成工作流，改进 Agent 创建、MCP 工具筛选与结构化控制，修复任务等待、权限模式和会话模式保持问题。
- MiniApp 与桌面卡片：完善 MiniApp 浏览器生命周期、实时业务操作和图像输入，扩展 DesktopCard 图表模板与主题适配，提升页面和文档控制的稳定性。
- 浏览器与电脑操作：支持窗口恢复、缩放观测和更可靠的导航与页面隔离，修复浏览器加载、子窗口激活、剪贴板和控制会话结束后的状态处理。
- 远程工作区：补齐远程 HTML 预览、CLI 文件浏览、SSH/WSL 诊断和 Peer Device 边界处理，优化缓存失效、路径兼容与连接失败提示。
- 会话与工作台：优化助手创建、会话导航、模型选择器、订阅页面和右侧面板状态，移动端 Web 完善助手图标、发送模式、会话模式和工作区交互。
- 流式体验与性能：降低流式渲染和历史上下文处理开销，优化请求首 token 指标、路由追踪、模型探测和大输出处理，修复多项流式投影边界问题。
- 稳定性与发布：修复 macOS 浏览器与安装器、Linux/WSL 子进程、Hook 环境、CI 测试和桌面开发隔离问题，提升跨平台构建与诊断可靠性。
