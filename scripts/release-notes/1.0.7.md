OpenBitFun 1.0.7 桌面端更新

- 外部会话历史：支持导入并继续 Codex 会话，新增 Cursor、Claude Code、OpenCode、Zcode、Pi 与 DeepSeek Harness 历史读取，会话索引与导航保持一致。
- 桌面卡片：新增 DesktopCard 工具与可浮动卡片窗口，提供概览区、设置与手动刷新，把命令和网页结果固定到桌面。
- 模型与 AI：新增可配置模型池、订阅账号路由与供应商配额，新增 DeepSeek 搜索提供方，完善模型选择与初始化向导。
- 电脑操作：输入后自动收敛弹窗，支持恢复最小化窗口与缩放屏幕观测，改进虚拟指针反馈、窗口发现与剪贴板保留，修复 Windows UIA 请求、macOS 后台控制及截图失败处理。
- 浏览器控制：跟踪页面加载状态并支持中止导航，补齐早期页面事件与历史恢复，外部 CDP 控制改为后台运行。
- 编辑与写作：新增可移动浮动批注编辑器、带原生剪贴板的输入框右键菜单，支持仓颉代码高亮，优化 Markdown 沉浸编辑。
- 工作台与规则：刷新助手工作流与工作台布局，新增原生全局规则及项目优先级，提供引导式 Agent 创建，创意技能按需路由。
- 性能与稳定：会话目录分页并复用版本化快照，减少大输出重复处理，保持模型请求前缀缓存稳定；诊断日志默认关闭敏感内容，修复 Linux 窗口框架与文件拖放、安装器依赖以及 macOS 公证重试。
- 移动端 Web：对话支持 KaTeX 数学公式渲染，修复流式图片、回滚与图片附件校验问题。
