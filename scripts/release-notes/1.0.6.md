OpenBitFun 1.0.6 桌面端更新

- 对话体验：新增后续输入建议，支持配置任务执行中的追问发送方式，优化消息操作、会话面板与 Markdown 表格显示。
- 会话与 Agent：支持从会话菜单复制会话、直接追问可复用子 Agent，完善 Agent 协作配置，修复历史加载与跨设备回滚后的状态同步。
- 浏览器与电脑操作：优化按任务导航、应用共享与授权范围控制，提升连续操作效率，修复浏览器连接隔离和截图等待行为。
- 远程工作区：完善 SSH 连接重新绑定与确认流程，修复跨设备缓存隔离、工作区归属及目录选择问题。
- 稳定性与性能：优化后台任务执行结果与报告投递、对话列表更新和 Git 远程轮询，修复 Markdown 解析与输入框键盘事件问题。
- macOS：修复全屏窗口关闭到托盘时的行为，完善窗口外观与原生应用图标打包。
