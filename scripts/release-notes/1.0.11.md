OpenBitFun 1.0.11 桌面端更新

- 长会话更流畅。减少流式 Markdown、工具组和并行 BTW 会话更新时的重复渲染，优化长会话首次打开、连续滚动和历史定位。
- 工作台与设置响应更快。优化工作区会话列表、标签切换、全局搜索和设置搜索；工作区历史支持移除条目，画布切换后保留编辑器布局。
- 新增手动压缩会话上下文的入口和基于模型的工具审批。改进模型分组配置、会话恢复时的工具历史，以及默认输出长度的选择。
- 改善跨设备和远程控制的断线恢复。修复远程会话归属、过期运行状态与权限回复丢失问题，并改进飞书、Telegram 和微信机器人的重连与消息重试。
- 新增 LaTeX 写作工作台，支持 PDF 预览、标注和编译反馈；完善加密 PDF 与审阅冲突的处理。
- 支持导入、预览和应用视觉皮肤包，取代原有皮肤市场入口。
- Windows 安装器支持恢复中断的安装、更新与卸载。macOS 改善旧版钥匙串凭据迁移，并缩短桌面前端资源加载时间。
