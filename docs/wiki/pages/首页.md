# OpenBitFun 使用指南

OpenBitFun 是开源的 Agent 工作空间，面向编程、调研、知识工作、内容创作和个人助理。它们共享工作空间，不需要先把每个需求严格划分为 Code 或 Cowork 模式。

## 从这里开始

1. [安装、配置模型并开始会话](快速开始)。
2. [选择 Harness](Agent-模式)：Minimal、Standard、Ultimate 或 Creative。
3. 检查智能体生成的文件、成果、来源和验证结果。

## 探索功能

- [产品全景](产品全景)：核心概念和能力地图。
- [编程工作台](编程工作台)与[调研、办公与内容创作](Cowork-与创作)：常见工作流程。
- [会话与持续目标](会话与持续目标)：历史、引导、分叉与持续工作。
- [个人助手](个人助手)与[任务板与定时任务](任务板与定时任务)。
- [Mini Apps 与 Pages](Mini-Apps-与-Pages)：创建工具、分享成果。
- [远程与多设备](远程与多设备)、[Peer Device Mode](Peer-Device-Mode-中文)与[Detached Dispatch](远程任务派发)。
- [语音与实时通话](语音与实时通话)、[自定义与扩展](自定义与扩展)、[安全与隐私](安全与隐私)。

## 版本与参考

本指南面向 OpenBitFun 1.0。文字于 2026-09-18 对照 v1.0.0 源码文档及开发版本 f72a28eb8 核验。连接服务、模型支持和不同表面的能力仍取决于安装版本与环境；源码核对不等于端到端实测。

旧 0.2.x 数据需要显式迁移，见[快速开始](快速开始)。可穿戴设备及更广泛的设备覆盖仍是发展方向，不代表每种设备都具有相同能力。
