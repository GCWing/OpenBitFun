# 产品全景

## 一个工作空间，多种工作场景

项目提供工作材料与环境；会话保存对话和活动记录；Harness 决定智能体如何推进任务；专门智能体提供角色指令和能力配置。Skills、MCP 与工具扩展能力，权限决定允许执行的操作。

编程与非编程是使用场景，不是严格分离的 Code/Cowork 模式。个人助手提供持续身份和专属上下文，也不应与通用 Harness 混为一谈。

## 四种 Harness

| Harness | 适合作为起点的任务 |
| --- | --- |
| Minimal | 目标明确的小任务、快速来回协作 |
| Standard | 需要规划与验证的日常多步骤工作 |
| Ultimate | 复杂调查与多智能体协调工作 |
| Creative | Mini App 创建与客户端定制 |

详见[Harness 选择](Agent-模式)。任务复杂度只是选择依据，不代表速度、成本或结果的保证。

## 能力地图

- 文件、编辑器、终端、Git、浏览器与预览：[编程工作台](编程工作台)。
- 调研、文档、演示文稿、表格、PDF 与可视化：[内容创作](Cowork-与创作)。
- 持久历史、目标、用量与上下文管理：[会话与持续目标](会话与持续目标)。
- 长期助手与重复工作：[个人助手](个人助手)、[定时任务](任务板与定时任务)。
- 专用界面与智能体会话结合的工具：[Mini Apps](Mini-Apps-与-Pages)。
- 静态页面版本与显式发布：[Pages](Mini-Apps-与-Pages)。
- 手机/Bot 控制、SSH/容器/WSL 工作区、设备控制和持久远程任务：[远程指南](远程与多设备)。
- 听写与实时语音协作：[语音](语音与实时通话)。
- 自定义智能体、Skills、MCP、Hooks、生态兼容与皮肤：[扩展指南](自定义与扩展)。

可用性取决于平台、模型配置、权限、运行时与服务部署。办公成果依赖相应 Skills 和工具，不代表任意模型无需配置就能生成所有格式。
