# 待补截图清单

本次仅刷新文字，不生成或上传截图。旧版首页图片已移除，正文用 S01–S36 标注待补位置，避免显示失效或误导界面。共 36 个截图主题；部分主题需要多张图片，并非强制 36 个文件。

P0 是入门、模式、执行归属或安全边界，优先补；P1 是主要功能；P2 是补充示例。

## 统一拍摄要求

- 使用同一已发布版本，记录版本、系统、语言和主题；若展示开发版新增能力，明确标注，不混入稳定版图。
- 中文页优先中文界面，英文页优先英文界面；演示数据尽量一致。无界面文字的通用图可共享。
- 使用演示项目与账号，隐藏 API Key、Bot Token、邮箱、私有仓库、敏感路径、IP 和个人文件。二维码/配对码使用失效演示值或遮盖，不发布有效访问凭据。
- 截图必须来自真实界面，保留关键状态与目标标识；不要为拍图执行删除、重置、发布或全权限授权。确认框停留在未提交阶段即可。
- 按主题保存为 `s03-harness-zh-cn.png` / `s03-harness-en-us.png` 等，需要多张时加 `-01`、`-02`。在 Wiki 可公开访问的素材地址上传后，用有意义的图片说明替换对应占位。
- 核对所有图片链接和相邻文字。截图用于说明界面，不视为功能或远程行为验证证据。
