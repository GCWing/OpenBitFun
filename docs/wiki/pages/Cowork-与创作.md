# 调研、办公与内容创作

本页保留旧地址以兼容已有链接，以下流程不要求进入单独的 Cowork 模式。

## 从目标出发

提供原始材料、目标受众、成果格式和验收标准。根据复杂度选择[Harness](Agent-模式)，并确认相应 Skills、工具、模型和依赖可用。

例如：

- “调研这个主题，比较来源，写一份带引用的简报。”
- “把这些笔记整理成可编辑演示文稿。”
- “分析这份表格，保留原件并解释公式。”
- “制作 PDF 指南，并检查渲染后的每一页。”

## 交付与验证

| 工作 | 交付前检查 |
| --- | --- |
| 文档 | 论据、层级、引用和渲染布局 |
| 演示文稿 | 叙事、版式、可编辑导出和字体 |
| 电子表格 | 公式、单位、原始数据和重算结果 |
| PDF | 页面渲染、裁切、文字和分页 |
| 调研 | 来源日期、一手证据、分歧和不确定性 |
| 可视化解释 | 数据准确、标签清晰和交互有效 |

成果生成取决于已安装 Skills 和执行环境。依赖或导出路径不可用时，应先解决或明确改用其他方案，不能把未支持的格式宣称为已完成。

## 在同一工作空间中迭代

请智能体修改实际保存的成果，而不只是描述假想修改；保留原始材料并检查新输出。交互解释可以留在会话中、成为[Mini App](Mini-Apps-与-Pages)，或保存并发布为 Page。

浏览器与桌面交互需要支持的工具和权限。购买、发消息、删除、发布等操作需要明确意图并检查结果。
