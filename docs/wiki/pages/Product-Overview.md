# Product overview

## One workspace, several kinds of work

A project supplies the working material and environment. A session preserves a conversation and its activity. A Harness shapes how the Agent executes the task. A specialist Agent supplies role-specific instructions and capabilities. Skills, MCP services, and tools extend what it can do; permissions determine what it may do.

Coding and non-coding work are scenarios, not a strict Code/Cowork split. Personal assistants add persistent identity and dedicated context rather than acting as another general Harness.

## Four Harnesses

| Harness | Suitable starting point |
| --- | --- |
| Minimal | Clear, bounded tasks and quick back-and-forth |
| Standard | Everyday multi-step work with planning and verification |
| Ultimate | Complex investigation and coordinated Agent work |
| Creative | Mini App creation and client customization |

See [Harness selection](Agent-Modes). Complexity is a useful starting point, not a guarantee about speed, cost, or outcome.

## Capability map

- Files, editor, terminal, Git, browser, and previews: [coding workspace](Coding-Workspace).
- Research, documents, slides, workbooks, PDFs, and visual explanations: [creation workflows](Cowork-and-Creation).
- Persistent history, goals, usage, and context management: [sessions](Sessions-and-Goals).
- Dedicated assistants and recurring work: [assistants](Personal-Assistant), [scheduling](Tasks-and-Automation).
- Installed tools with dedicated interfaces and Agent conversations: [Mini Apps](Mini-Apps-and-Pages).
- Static page versions and intentional publishing: [Pages](Mini-Apps-and-Pages).
- Mobile/Bot control, SSH/container/WSL workspaces, peer devices, and durable remote jobs: [remote guide](Remote-and-Multi-device).
- Speech transcription and realtime spoken collaboration: [voice](Voice-and-Realtime).
- Custom Agents, Skills, MCP, Hooks, ecosystem compatibility, and skins: [extensions](Customize-and-Extend).

Availability varies by platform, configured model, permissions, runtime, and service deployment. Office artifacts depend on the relevant Skills and tools; they are not a promise that every model can generate every format without setup.
