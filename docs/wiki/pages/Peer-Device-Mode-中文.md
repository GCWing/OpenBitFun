# Peer Device Mode

## 使用另一设备的工作空间

Peer Device Mode 保留本地控制端界面，产品命令与事件来自选定的 OpenBitFun Desktop 或 CLI 宿主。对端拥有执行、会话、文件系统、终端和权限交互。

它不同于 SSH 工作区 IO，也不同于提交[派发任务](远程任务派发)。

## 连接

1. 配置账号/Relay 服务，在相关设备使用 GitHub 登录。
2. 打开 Remote Connect 设备管理，检查同账号设备和在线状态。
3. 连接目标设备，进入其受支持设备表面。
4. 选择对端真实存在的工作区，再打开或创建会话。
5. 修改文件或运行命令前确认设备标识与路径。

能力由目标宿主提供，Desktop 与 CLI 不一定完全一致；不支持的操作应明确报告，而不能悄悄在控制端执行。

## 归属与断线

两台设备上看起来相同的路径仍是不同资源，不能将控制端路径复用为对端执行路径。下载目的地属于控制端，源文件属于对端。

切回本地视图不等于取消或关闭对端工作。已接受任务仍属于执行运行时，即使没有控制端连接，只要运行时保持可用；重连可恢复历史和未回答交互。

窗口、账号身份和部署等控制端本地操作，不会因为处于对端视图就变成远程操作。保护两台设备，撤销过时访问。
