# Screenshot checklist

This refresh changes text only. No screenshots were generated or uploaded. Obsolete Home images were removed; S01–S36 identify pending illustration positions. There are 36 topics, not necessarily 36 image files.

P0 covers onboarding, execution ownership, selection, or safety; P1 covers primary features; P2 covers supporting examples.

## Capture requirements

- Use one released version and record version, OS, language, and theme. Label development-only examples explicitly.
- Prefer Chinese UI for Chinese pages and English UI for English pages, with consistent demo data. Language-neutral images may be shared.
- Use demo accounts/projects. Hide API keys, Bot tokens, emails, private repositories, sensitive paths/IPs, and personal files. Invalidate or redact QR/pairing codes; never publish live credentials.
- Capture real UI and retain important state/target indicators. Do not delete, reset, publish, or grant Full Access just to capture a screenshot; leave confirmation dialogs unsubmitted.
- Use names such as `s03-harness-zh-cn.png` and `s03-harness-en-us.png`, adding `-01` or `-02` when needed. Upload to a publicly accessible Wiki asset URL and replace the corresponding placeholder with an informative caption.
- Check image links and surrounding instructions. Screenshots illustrate UI; they are not evidence of remote behavior testing.
