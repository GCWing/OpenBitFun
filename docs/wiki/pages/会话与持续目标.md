# 会话与持续目标

## 创建与整理

在目标工作区新建会话，首轮前选择 Harness/智能体，再核对模型与权限。按需重命名、归档、恢复、搜索、分叉或导出。删除不同于归档，需要明确意图。

检查工具输出、修改文件、后台命令和等待交互，不要只依赖最后一句完成说明。

## 引导、打断与恢复

通过支持的引导流程补充指令，重定向正在进行的工作；确认排队消息状态，不要假设已执行。按需打断或取消，但这不会撤销已完成的编辑或外部影响。

恢复依赖持久会话/运行时状态与执行宿主。连接丢失不证明任务已停止，重试提交前确认宿主与会话身份，避免重复执行。

## 分叉与上下文

分叉对话可以探索另一方向，它复制选定历史，不自动创建 Git worktree 或复制文件。远程分叉保留连接与 POSIX 路径，共享原工作树。

上下文重载、指令初始化、记忆管理和压缩改变模型可见信息，不一定删除持久历史。重置记忆与删除会话是不同操作。

支持时可使用 BTW 轻量问答或编辑器内联 AI 处理旁支问题，并保持主任务范围明确。

## 持续目标

需要持久目标时，明确请求创建会话目标，检查目标说明和状态，按需编辑或清除。应根据真实进展完成目标或标记阻塞，而非仅凭工具次数。

目标不是时间表，未来运行使用[定时任务](任务板与定时任务)，目标主机拥有的远程执行使用[派发](远程任务派发)。

支持时查看会话请求、Token 与成本报告。服务定价与报告估算可能不同，重要账单假设需向服务商核实。
