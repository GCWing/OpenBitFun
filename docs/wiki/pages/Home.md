# OpenBitFun Wiki

OpenBitFun is an open-source Agent workspace for coding, research, knowledge work, creation, and personal assistance. These tasks share a workspace: you do not need to sort every request into separate Code and Cowork modes.

## Start here

1. [Install, configure a model, and start a session](Getting-Started).
2. [Choose a Harness](Agent-Modes): Minimal, Standard, Ultimate, or Creative.
3. Inspect the files, artifacts, sources, and checks that the Agent produces.

## Versions and references

This guide targets OpenBitFun 1.0. Text was checked on 2026-09-18 against the v1.0.0 source documentation and development revision f72a28eb8. Connection services, provider support, and surface capabilities still depend on your installation and environment. Source review is not end-to-end testing.

Legacy 0.2.x data needs explicit migration; see [Getting started](Getting-Started). Wearables and broader device coverage remain development directions, not promises of identical capability on every device.
