# 个人助手

个人助手为长期职责保留专属身份和上下文，不是额外的通用 Harness，也不要求把普通工作划分为 Code 与 Cowork。

## 创建与配置

1. 打开“助理”，创建或选择一个助理。
2. 定义名称、角色、头像和协作风格。
3. 检查身份与人设文件：IDENTITY.md、SOUL.md、USER.md。
4. 配置相应 Skills、内置工具、MCP 服务与模型。
5. 从助理卡片或详情页开始对话。

新助理默认能力配置决定其初始能力。注意启用、不可用、遮蔽和已更改项；不要假设修改默认值会重写所有已有助理。

## 持续工作

每个助理拥有自己的工作区和会话。重复工作使用[定时任务](任务板与定时任务)，并确认执行主机和所需服务保持可用。编写人设文件本身不会创建后台任务。

## 记忆与洞察

长期记忆可按配置保留会话中的持久偏好与知识，应与身份配置分开检查和管理。清除记忆不等于删除会话历史。

会话洞察汇总选定时间段的活动，应作为反思报告使用，重要结论仍需对照实际工作确认。

语音输入、实时通话和可选桌面伙伴是独立能力，见[语音](语音与实时通话)。重置工作区或删除助理是明确的数据操作，先备份需要保留的材料。
