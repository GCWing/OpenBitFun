# Findings

- OpenAI Help Center defines Intelligent UI as ChatGPT combining text, visuals and interactive elements; GPT-6 composes graphics, buttons, forms, charts and interactive experiences. The page describes the feature but does not announce source code or a license: https://help.openai.com/en/articles/20001598-intelligent-ui-in-chatgpt
- OpenAI says Apps SDK is open source, built on MCP; it lets developers define app logic/UI and run apps inside ChatGPT: https://help.openai.com/en/articles/12515353-building-with-the-apps-sdk
- OpenAI's developer quickstart says ChatGPT implements the open MCP Apps UI standard, where an optional web component is rendered in an iframe; recommends standard MCP Apps bridge and optional window.openai extensions: https://developers.openai.com/plugins/build/app-quickstart
- OpenAI's apps announcement says Apps SDK is an open standard built on MCP and open source; apps define interface/chat logic with own code. https://openai.com/index/introducing-apps-in-chatgpt/
- Official OpenAI apps-sdk-ui package is public and MIT licensed; description is a design system for building apps for ChatGPT with Apps SDK: https://github.com/openai/apps-sdk-ui/blob/main/package.json
- Official examples repo is MIT and includes Pizzaz, solar-system, kitchen-sink and authenticated widgets: https://github.com/openai/openai-apps-sdk-examples
- thesysdev/open-intelligent-ui is a public MIT repo explicitly described as an independent open-source implementation of the Intelligent UI experience, built on OpenUI. It streams OpenUI Lang and renders maps/photos/charts/drawings/tools; disclaimer says unaffiliated with OpenAI: https://github.com/thesysdev/open-intelligent-ui
- thesysdev/openui is MIT, a full-stack framework-agnostic generative UI framework with OpenUI Lang, streaming renderers for React/Vue/Svelte/Angular, component libraries and chat surfaces: https://github.com/thesysdev/openui
- MCP-UI is Apache-2.0; creates UI resources over MCP and renders them in sandboxed iframes; supports MCP Apps hosts including Claude, VS Code, Goose, LibreChat, etc. Its roadmap still lists generative UI as future work, so it is better for server-defined tool UIs than open-ended automatic composition: https://github.com/MCP-UI-Org/mcp-ui
- CopilotKit generative-ui repo describes three patterns (controlled AG-UI, declarative A2UI/Open-JSON-UI, open-ended MCP Apps) and OpenGenerativeUI, where an agent emits HTML/SVG/Canvas into a sandboxed iframe; OpenGenerativeUI repo says MIT: https://github.com/CopilotKit/generative-ui and https://github.com/CopilotKit/OpenGenerativeUI
- Google A2UI is an open-source Apache 2 project for declarative, cross-platform agent-generated UI from trusted component catalogs, with native renderers and streaming updates: https://developers.googleblog.com/introducing-a2ui-an-open-project-for-agent-driven-interfaces/ and https://github.com/a2ui-project/a2ui
- Vercel AI SDK is an open-source provider-agnostic TypeScript toolkit; its UI module has hooks for chatbots and generative UIs: https://github.com/vercel/ai
