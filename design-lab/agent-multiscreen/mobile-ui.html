三端的组件和样式可以保持一致吗？
已思考 4 秒
对比三个平台的 token 映射，确认共享的是语义角色而不是具体数值。

可以。三个平台共享同一套视觉契约，但各自保留原生渲染——共享的是语义角色，不是像素。

  • 颜色、字阶、几何、动效全部来自 mobile-tokens.json
  • 组件只声明它消费哪些 token 角色
  • 安全区、键盘、无障碍桥接仍由各平台自己负责

契约只记录稳定事实，渲染器的选择留给宿主：
